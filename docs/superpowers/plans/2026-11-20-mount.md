# `pithos mount` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pithos mount` adds or removes host paths in `<project>/.pithos.toml`, editing the file's text without reformatting it, then trusts what it wrote.

**Architecture:** the text splicing is pure functions in `config.py` (next to the project-file reading and the trust store). The command, its path checks and its output live in `pithos` next to `cmd_allow`.

**Tech Stack:** Python 3.11 standard library only (`tomllib` reads; `re` and a small span scanner write).

**Spec:** `docs/superpowers/specs/2026-11-20-mount-design.md`

## Global Constraints

- Standard library only; no new module, no new dependency.
- Every value printed goes through `config.clean()`.
- Validation errors raise `ConfigError` naming the key or path.
- Tests are `unittest` style, run under `pytest`, use the fake `HOME` from `tests/helpers.scratch_dir`.
- Never weaken a pithos invariant; the project file stays read-only inside the sandbox (`ALWAYS_RO_IN_PROJECT` is not touched).

## Review Focus

1. A hand-written `.pithos.toml` with comments and multi-line arrays must survive the edit byte-for-byte outside the changed entry (Task 1).
2. A file changed since it was trusted must be refused with the file untouched (Task 3).
3. A credentials path (`~/.ssh`, `.env`, `.netrc`) must be refused rather than written and then refused at `run` (Task 3).
4. `[fs]` as the last table, or a file without a trailing newline, must still produce a parseable file (Task 1).
5. Adding the same path twice must be a no-op, not a duplicate and not an untrusted-file error (Task 2).

- [ ] **Step 3: Implement the scanner and `edit_list`**

The scanner is the one part the tests don't spell out. It walks the array body and only accepts
strings, commas, whitespace and comments; a comment ends at the newline; inside `"` a backslash
skips the next character; `"""` and `'''` are refused:

```python
def toml_array_spans(text, start):
    if text[start] != "[":
        raise ConfigError(f"{PROJECT_FILE}: expected a list")
    spans, i = [], start + 1
    while i < len(text):
        c = text[i]
        if c in " \t\r\n,":
            i += 1
        elif c == "#":
            end = text.find("\n", i)
            i = len(text) if end < 0 else end
        elif text[i:i + 3] in ('"""', "'''"):
            raise ConfigError(f"{PROJECT_FILE}: multi-line strings are not supported")
        elif c in "\"'":
            j = i + 1
            while j < len(text) and text[j] != c:
                j += 2 if c == '"' and text[j] == "\\" else 1
            if j >= len(text):
                raise ConfigError(f"{PROJECT_FILE}: unterminated string")
            spans.append((i, j + 1))
            i = j + 1
        elif c == "]":
            return spans, i
        else:
            raise ConfigError(f"{PROJECT_FILE}: unsupported value in the list")
    raise ConfigError(f"{PROJECT_FILE}: unterminated list")
```

`edit_list`: locate `[fs]` with `^[ \t]*\[[ \t]*fs[ \t]*\][^\n]*\n`; if absent, refuse when
`^[ \t]*fs[ \t]*[.\[]` matches, else append `[fs]\n{key} = [...]\n` (a `"\n"` first when the text
does not end in one). Inside the body, locate `^[ \t]*{key}[ \t]*=[ \t]*`; if absent, append the
key as a new line at the end of the body (with a `"\n"` first when the body does not end in one)
and refuse a removal. If present, the value must start with `[`.

Remove each value by decoding each literal with `tomllib.loads("v = " + literal)["v"]`, dropping
its span with `drop_span` (prefer the comma before it when only whitespace separates them, else
the one after, else neither), then rescanning. Add by inserting `, {json.dumps(value)}` after the
last span, or `{json.dumps(value)}` into an empty array, skipping values already present.
`json.dumps` produces a valid TOML basic string.

`short_path`: return `"{project}" + real[len(project):]` when `real` is strictly inside `project`,
else `"~" + real[len(home):]` when strictly inside `paths.home`, else `real`.

- [ ] **Step 3: Implement**

`config.trust_project` does what `cmd_trust` does today: `read_trusted`, set the digest of `raw`,
`os.makedirs(paths.state, mode=0o700, exist_ok=True)`, `write_private_json(paths.trusted, …)`.
`cmd_trust` then calls it, so the two paths can't drift.

`cmd_mount`:

1. `PITHOS` guard; argument checks (`--list` takes nothing else; `--remove` takes no `--rw`; no
   paths and no `--list` is an error).
2. `project = resolve_project(args.project)`; `check_project(project, paths)`.
3. `raw, digest = read_project_file(project)`; `data = parse_project_file(project, raw) if raw else {}`.
4. `--list`: print `fs.ro` and `fs.rw` as JSON, return 0 (no trust needed to read).
5. Refuse when `read_trusted(paths).get(project) != digest`.
6. For each path: `value = raw if raw.startswith(("/", "~", "{")) else os.path.join(project, raw)`;
   `dest = expand_path(value, project, paths)`; must exist; `src = os.path.realpath(dest)`;
   `entry = short_path(src, project, paths)`; then `check_project_link("pithos mount", dest, src,
   project)`, `check_bind(src, expand_path(entry, project, paths), paths, denied_roots)`,
   `is_sensitive(src)` and `is_sensitive(src, deny_patterns(data, project, paths))` as refusals.
   `denied_roots` is the realpaths of the non-glob `fs.deny` entries.
7. Build `changes: dict[str, tuple[list, list]]` for `"ro"` and `"rw"` (adds, removes) and a
   report of `(sign, key, entry)`: an entry already in the target list reports `"="`; one in the
   other list reports `"-"` for that key and `"+"` for the target; `--remove` removes from both.
8. Apply `edit_list` per changed key, then compare `parse_project_file(project, new_text.encode())`
   with a `copy.deepcopy(data)` updated the same way; mismatch → `ConfigError` (edit by hand).
9. No changes → print the report and return 0.
10. `write_project_file(project, text, mode)` with the old mode (`os.stat(path).st_mode & 0o777`)
    or `0o644`, then `trust_project(paths, project, text.encode())`.
11. Print the report (`+ fs.ro ~/data`, `- fs.rw ~/data`, `= fs.ro ~/data (already listed)`), then
    `trusted <project>/.pithos.toml` and `mounts apply from the next session`.

`parse_args`: add `"mount"` to `COMMANDS`, to the `-C` tuple, and a branch with
`paths` (`nargs="*"`, metavar `PATH`), `--rw`, `--remove`, `--list`. `main` maps `"mount"` to
`cmd_mount`.
